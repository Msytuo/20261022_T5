
# Cálculo del Area de una figura

- En este programa se va a calcular el área de una figura cualquier ( siempre, que este programada, es decir, sea valida ).
- El programa esta hecho para que siempre te pida una figura, es decir, nunca sale del bucle.
- Las figuras incluidas de momento son el círculo, rectángulo, cuadrado y triángulo.





## Instalacion

Solo debes descargar el archivo .zip.
Una vez dentro solo debes ejecutar el programa con:

```bash
 python .\area.py
```
